# Pike County Golf Carts - Commitment to Digital Accessibility

## CONFORMANCE STATUS
We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. 
These guidelines explain how to make web content accessible to people with disabilities. 
Conformance with these guidelines helps us ensure the site is accessible to blind and visually 
impaired users, deaf and hearing impaired users, users with learning disabilities, cognitive 
limitations, limited movement, speech disabilities, photosensitivity, and combinations of these.

### WCAG 2.1 Compliance Level: AA Target

## ACCESSIBILITY FEATURES IMPLEMENTED

### Visual Accessibility
✓ High contrast color schemes for improved readability
✓ Scalable text that can be enlarged up to 200% without loss of functionality
✓ Alternative text descriptions for all images and graphics
✓ Consistent and logical heading structure (H1-H6)
✓ Focus indicators for keyboard navigation
✓ Color is not used as the only visual means of conveying information

### Motor/Mobility Accessibility  
✓ Full keyboard navigation support
✓ Keyboard focus management and logical tab order
✓ Adequate target sizes for clickable elements (minimum 44x44 pixels)
✓ No time limits on content interaction
✓ Skip navigation links for efficient page traversal

### Cognitive Accessibility
✓ Clear and simple language throughout the website
✓ Consistent navigation and page layouts
✓ Error identification and suggestion in forms
✓ Descriptive page titles and headings
✓ Logical reading and navigation order
✓ Clear instructions for all interactive elements

### Hearing Accessibility
✓ Captions and transcripts for video content (when available)
✓ Visual alternatives to audio-only information
✓ No audio that plays automatically
✓ Contact information available in multiple formats (phone, email, web form)

## CONTENT ACCESSIBILITY

### Images and Media
- All images include alternative text descriptions
- Decorative images are marked appropriately for screen readers
- Product images include detailed descriptions of golf cart features
- Company photos include contextual descriptions
- No essential information is conveyed through images alone

### Navigation and Structure
- Consistent navigation across all pages
- Breadcrumb navigation on deep pages
- Skip links to main content
- Logical heading hierarchy
- Clear page titles describing page purpose

### Forms and Interactive Elements
- All form fields have associated labels
- Required fields are clearly identified
- Error messages are descriptive and helpful
- Submit buttons have clear action descriptions
- Form validation provides clear feedback

### Text and Content
- Plain language used throughout the site
- Technical terms explained when necessary
- Content organized in logical sections
- Important information highlighted appropriately
- Adequate spacing between clickable elements
