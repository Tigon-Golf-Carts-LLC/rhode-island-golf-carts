## SCHEMA IMPLEMENTATION GUIDELINES

### JSON-LD Placement:
- Include in <head> section of HTML
- One script tag per schema type
- Validate before deployment

### Required Properties:
- All LocalBusiness schemas require name, address, telephone
- All Product schemas require name, offers, description
- All Service schemas require name, provider

### Best Practices:
- Keep schemas accurate and up-to-date
- Include images where applicable
- Use specific types (AutomotiveDealer vs LocalBusiness)
